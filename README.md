
# TypeScript Assignment

## Assignment Overview

This assignment covers fundamental and OOP TypeScript concepts through eight practical problems.

### Topics Covered

1. Optional parameters and default values.
2. Union types and type narrowing.
3. Readonly tuples.
4. Generic functions and rest parameters.
5. Interfaces and array filtering.
6. Generics with `keyof` constraints.
7. Classes, inheritance, and access modifiers.
8. Asynchronous programming with Promises and error handling.
